# dsh-enkeep

> dsh-enkeep makes dsh better.

一个 DeepSeek Harness (DSH) 插件项目。

## 状态

🚧 初始化完成，开发中。

## 安装

```sh
dsh plugin --profile web add <package-spec>
```

## 开发

```sh
pnpm install
pnpm run typecheck
pnpm run build
```
